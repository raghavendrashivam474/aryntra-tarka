# Tarka Roadmap

---

## Version 1.0 — Complete

- Multi-tool autonomous planning
- Streaming responses (SSE)
- Persistent conversations (SQLite)
- Transparent tool execution with badges
- Responsive UI (desktop + mobile)
- Session history sidebar
- Settings page
- Production deployment (Vercel + Render)

---

## Version 2.0 — Planned

### Intelligence
- Web search integration
- RAG (Retrieval-Augmented Generation)
- File understanding (PDF, DOCX, images)
- Code execution sandbox

### Platform
- Authentication (OAuth / email)
- Cloud sync
- Shareable conversation links
- Team workspaces

### Interface
- Voice input and output
- Image understanding
- Rich file attachments
- Mobile app

### Extensibility
- Plugin ecosystem
- Custom tool registration UI
- Webhook triggers

---

## Guiding Principle

Every version extends the product without replacing the core.
The layered architecture in Version 1 supports all Version 2 features
as additions, not rewrites.
