# Sprint 1 — First Inference

**Version:** v0.2.0

---

# Objective

Build the first complete inference pipeline for Aryntra Tarka.

Sprint 1 transforms the project from an architectural foundation into a functional AI backend capable of accepting a client request, invoking a language model through the provider abstraction, and returning a validated response.

---

# Background

Sprint 0 established the project's foundation:

- Repository structure
- FastAPI application
- Configuration management
- Logging infrastructure
- Provider abstractions
- Documentation
- Verification framework

No AI inference was implemented during Sprint 0.

Sprint 1 introduces the first real interaction with a language model.

---

# Scope

## Included

- Request models
- Response models
- Inference service
- Provider factory integration
- Ollama provider implementation
- Basic inference endpoint
- Input validation
- Output validation
- Error handling
- End-to-end verification

---

## Explicitly Excluded

- Conversation memory
- Retrieval
- Vector search
- Tool execution
- Agents
- Prompt templates
- Streaming responses
- Authentication
- Rate limiting
- Multi-turn conversations

These capabilities belong to future sprints.

---

# Architectural Goal

```
Client
    │
    ▼
Inference Endpoint
    │
    ▼
Request Validation
    │
    ▼
Inference Service
    │
    ▼
Provider Factory
    │
    ▼
Selected Provider
    │
    ▼
Language Model
    │
    ▼
Response Validation
    │
    ▼
Client Response
```

---

# Expected Outcome

At the end of Sprint 1, a client should be able to submit a prompt and receive a real response generated by the configured language model through Tarka's provider architecture.

Example:

Request

```http
POST /chat
```

```json
{
    "message": "Explain recursion in one sentence."
}
```

Response

```json
{
    "response": "Recursion is a function calling itself until a stopping condition is met."
}
```

# Design Principles

Sprint 1 continues the architectural principles established during Sprint 0.

- Provider agnostic
- Modular by design
- Strong separation of concerns
- Validation first
- Configuration driven
- Extensible architecture
- Clean service boundaries

# Success Criteria

Sprint 1 will be considered complete when:

- Request models validate correctly
- Response models validate correctly
- Inference endpoint is operational
- Provider factory resolves providers successfully
- Ollama provider returns real responses
- Invalid requests return appropriate errors
- Logging captures inference lifecycle
- Documentation is updated
- Verification checklist passes
